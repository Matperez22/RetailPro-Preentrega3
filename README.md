# RetailPro - Pre Entrega 3

## Modelo de Ventas de Tecnología

Proyecto desarrollado en SQL Server para modelar una base de datos de ventas de productos tecnológicos.

### Contenido del proyecto

La base de datos incluye las siguientes tablas:

- territorios
- clientes
- categorias
- productos
- ventas

### Funcionalidades implementadas

- Creación de tablas.
- Definición de claves primarias (PK).
- Definición de claves foráneas (FK).
- Relaciones entre las tablas.
- Carga inicial de datos.
- Registro de transacciones de ventas.
- Consultas mediante JOIN.
- Consultas de control.
- Validación de integridad referencial.

### Archivo SQL

El archivo RETAILPRO_PREENTREGA3_SQL.sql contiene el script completo para la creación y prueba de la base de datos.
